Create and maintain a complete cross-platform Unicode text editor named "Avestan Editor".

1. Use Go and Fyne. Support Linux, Windows, and Android; follow current repository patterns and keep settings, language data, and strings in embedded assets.
2. Build a normal multiline text editor using Fyne's native widget.Entry. Preserve native typing, caret, mouse selection, clipboard, undo, and mobile keyboard behavior. The editor must fill all available horizontal space, wrap long lines, and scroll vertically.
3. Support opening, editing, saving, and Save As for UTF-8 and UTF-16 documents. Warn before overwriting an existing file. On exit with unsaved changes, show Yes/No/Cancel and implement each choice correctly.
4. Put Open, Save, Save As, Settings, About, and a checked-by-default "Right to left" checkbox in the top bar; put Exit at the top right. Place the RTL checkbox immediately after About. Persist its state. When checked, right-align editor text; when unchecked, left-align it. Do not change keyboard direction.
5. Add a language selector above the software keyboard. Order its first choices as Avesta, Pahlavi, Parthian, and Ancient Persian, then other ancient Iranian scripts, other Unicode scripts/languages, general symbols, and all printable Unicode. Use the latest Unicode tables available in the Go toolchain. Show each language name with a sample in its own script where available.
6. Show every printable character available for the selected script on the software keyboard. Each key label must have exactly this layout: one space, the character, one space, then its reading. Display combining marks with a dotted-circle preview but insert only the mark. Keyboard taps must insert at the native editor's current caret without losing editing behavior.
7. Provide accurate, source-backed readings in embedded data. Do not invent pronunciations or claim one universal reading for characters with context-, language-, or tradition-dependent values. Show the Unicode code point when no verified reading exists. Document the sources and coverage.
8. Provide a dark metallic default theme and a light/system alternative. Put theme, text-size, font selection, and "Use bundled font" controls in one Settings dialog. Apply changes immediately and persist them. Include the licensed bundled Unicode fallback font and its attribution/license; validate imported TTF/OTF fonts.
9. About dialog: show the app icon and "Avestan Editor" together, version "1.0" below the name, copyright "Copyright (c) 2026 @ArdeshirV, Licenced under GPLv3+", and project link "https://github.com/ArdeshirV/cuneiform". Keep the app name at 70% of the former three-times-theme-title size. Show only these requested information values, without field labels.
10. Persist the editor/keyboard splitter position; default to 70% keyboard height. Keep UI labels and configurable numeric values in assets, not scattered hard-coded strings or numbers.
11. Maintain English and Persian READMEs and update both when user-facing behavior changes. Keep documentation consistent with the actual app.
12. Add focused regression tests for editing, caret insertion, RTL alignment/persistence behavior, keyboard labels, and document handling. Run gofmt, relevant tests, JSON validation, and a Go build; report environmental blockers honestly.
13. Make precise changes only. Preserve unrelated worktree changes, do not claim unimplemented behavior, and do not replace native Fyne editor behavior with custom caret or mouse-position logic.
