Unicode Script Fallback
=======================

The bundled UnicodeScriptFallback.ttf is a merged font renamed "Cuneiform
Script Fallback". It includes Noto Naskh Arabic/Persian shaping and Noto fonts
for ancient and historic scripts. The Noto font software is copyright Google
LLC and licensed under SIL Open Font License 1.1. The full license is in
LICENSE.txt. Noto source: https://github.com/notofonts
